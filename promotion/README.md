# Promotion Gate

Promotion Gate converts a validated shader instrument into an append-only REFRACT registry version and an explicit Unreal translation handoff.

It fails closed when the visual-behavior schema, semantic controls, direct-manipulation uniforms, destination contract, or append-only rule is missing. A generated registry is not considered fully promoted until the web/Spline runtime checks and Unreal live material compile pass.

The first candidate is `organic-glow-instrument.v1.json`, sourced from the preserved `Refract_Motion_Studio_v3` iteration.
